# Paper Atlas

Paper Atlas 是一个在本地运行的论文库浏览器。它把论文按研究方向和年份排成时间泳道，并在需要时显示库内论文之间的引用关系。

![Paper Atlas 界面](preview.png)

当前版本：v0.9

## 主要功能

- 按类别和年份浏览论文，年份从左到右排列。
- 单击论文节点查看它与库内其他论文的引用关系；双击打开论文详情。
- 在详情中查看标题、作者、年份、摘要、分类和引用信息。
- 分别搜索最新 arXiv 论文与多篇论文共同引用的候选论文。
- 候选论文会自动分类，可以查看摘要、加入论文库或忽略。
- 加入论文库后下载 PDF，并重新生成图谱数据。
- 搜索主题、共同引用次数下限和候选状态都保存在本地。

## 使用

### macOS 应用

双击仓库中的 `Paper Atlas.app`。首次打开时选择论文库目录，之后应用会记住该位置。

如果 macOS 阻止首次运行，请在 Finder 中右键应用，选择“打开”。

### 命令行

需要 Python 3.10 或更高版本。

```bash
make start
```

这个命令会启动本地服务并打开浏览器。它适合 Windows、Linux，或不想使用 macOS 应用时使用。

## 论文库目录

默认情况下，项目目录的上一级就是论文库。PDF 放在对应类别目录中；程序生成的数据保存在 `web/data/`，不会修改论文内容。

当前分类为：

```text
01_模型架构与训练优化
02_注意力机制与长上下文
03_MoE与稀疏模型
04_量化与低精度计算
05_分布式训练与数据基础设施
06_GPU内核_编译器与性能工程
07_GPU内核智能体与自动调优
08_通用智能体与自主学习
09_生成模型与视频系统
10_大模型技术报告与推理训练
```

新增 PDF 后运行：

```bash
make update
```

它会整理新增论文、提取元数据并重建图谱。

## 论文发现

应用里的“搜索 arXiv”和“共同引用”是两套独立入口：

- 搜索 arXiv：按已配置的主题查找近期论文。
- 共同引用：从现有论文的参考文献中，找出被多篇论文共同引用的候选项。

搜索结果只会进入候选列表，不会自动下载。点击“加入论文库”后，论文才会归档并出现在图谱中。

对应的命令行入口是：

```bash
make discover
make discover-shared
```

论文发现需要网络连接，并会访问 arXiv 与 OpenAlex。

## 常用命令

| 命令 | 用途 |
| --- | --- |
| `make start` | 启动浏览器版本 |
| `make update` | 整理论文并重建图谱 |
| `make discover` | 搜索最新 arXiv 论文 |
| `make discover-shared` | 生成共同引用候选 |
| `make test` | 运行测试 |
| `make mac-app` | 重新生成 macOS 应用 |

## 仓库内容

仓库包含应用代码、生成后的图谱元数据和候选记录，不包含论文 PDF。论文标题、摘要、作者和引用信息来自公开论文页面与开放学术数据源。

## 开发

```bash
python3 -m pip install -r requirements.txt
make test
```

前端不需要 npm 构建。修改 `app/` 中的文件后刷新页面即可；如果修改了 macOS 外壳，再运行 `make mac-app`。
